# Architecture Decision Records

Dieses Verzeichnis dokumentiert wichtige Designsystem- und CSS-Architekturentscheidungen.
Ein ADR hält Kontext, Entscheidung und Folgen fest; es wird nicht nachträglich
umgeschrieben, wenn sich die Entscheidung ändert. Stattdessen wird sein Status
auf `Abgelöst` gesetzt und ein neuer ADR verlinkt.

## Neue ADRs

Neue Einträge erhalten die nächste fortlaufende vierstellige Nummer und einen
kurzen, kleingeschriebenen Dateinamen. Verwende mindestens diese Abschnitte:

- Titel, Status und Datum
- Kontext und Problem
- Entscheidung
- Folgen und offene Punkte

Ein ADR beschreibt eine konkrete Entscheidung, keine Aufgabenliste. Verknüpfe
verwandte oder ablösende Einträge und aktualisiere diese Übersicht.
